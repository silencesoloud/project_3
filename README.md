# Задача Иосифа — разбор кода

## Условие задачи

Вокруг считающего стоят N человек, занумерованных от 1 до N по часовой стрелке. Считающий ведёт счёт до M; тот, на ком остановился счёт, выходит из круга. Счёт продолжается со следующего человека до тех пор, пока не останется один.

Определить:
- **а)** номер оставшегося, если счёт начинался с человека №1;
- **б)** номер человека, с которого начинался счёт, если известен номер оставшегося L.

---

## Структура данных — кольцевой список

Люди хранятся в кольцевом односвязном списке: последний узел ссылается на первый.

```
1 → 2 → 3 → 4 → 5 → 6
↑                     │
└─────────────────────┘
```

```cpp
struct Node {
    int number;   // Номер человека в круге
    Node* next;   // Указатель на следующего
    Node(int n) : number(n), next(nullptr) {}
};
```

---

## `buildCircle(N)` — построение кольца

Создаёт N узлов с номерами 1..N и замыкает список в кольцо.

```cpp
Node* buildCircle(int N) {
    Node* head = new Node(1);
    Node* cur = head;
    for (int i = 2; i <= N; i++) {
        cur->next = new Node(i);
        cur = cur->next;
    }
    cur->next = head; // замыкаем кольцо
    return head;
}
```

---

## `simulate(N, M, start, verbose)` — симуляция выбывания

Моделирует процесс выбывания на кольцевом списке. Используется в `solvePartB`, проверке и демонстрации.

**Параметры:**

| Параметр  | Описание                                  |
|-----------|-------------------------------------------|
| `N`       | Исходное количество людей                 |
| `M`       | Каждый M-й человек выбывает               |
| `start`   | Узел, с которого начинается отсчёт        |
| `verbose` | Если `true` — выводит пошаговый лог       |

```cpp
int simulate(int N, int M, Node* start, bool verbose = false) {
    // Находим узел перед start — нужен для удаления через prev->next
    Node* prev = start;
    while (prev->next != start) prev = prev->next;

    int remaining = N;
    while (remaining > 1) {
        // M-1 шаг вперёд: prev встаёт перед выбывающим
        for (int i = 0; i < M - 1; i++) prev = prev->next;

        Node* toRemove = prev->next;  // выбывающий
        prev->next = toRemove->next;  // вырезаем из кольца
        delete toRemove;
        remaining--;
    }

    int survivor = prev->next->number;
    delete prev->next;
    return survivor;
}
```

**Почему M–1, а не M шагов?**  
`prev` уже стоит на последнем человеке предыдущего счёта. Новый счёт начинается с `prev->next`, поэтому до выбывающего остаётся ровно M–1 шаг.

**Пример: N = 6, M = 3**

| Шаг | prev до сдвига | Сдвиг (M–1=2) | Выбывает | Остались    |
|-----|----------------|----------------|----------|-------------|
| 1   | 6              | 6→1→2          | 3        | 1 2 4 5 6   |
| 2   | 2              | 2→4→5          | 6        | 1 2 4 5     |
| 3   | 5              | 5→1→2          | 4        | 1 2 5       |
| 4   | 2              | 2→5→1          | 2        | 1 5         |
| 5   | —              | —              | —        | остался **5** |

## `solvePartA(N, M)` — часть а)

Использует рекуррентную формулу Иосифа за O(N):

```
J(1) = 0
J(n) = (J(n-1) + M) % n
Ответ = J(N) + 1  (перевод в 1-индексацию)
```

```cpp
int solvePartA(int N, int M) {
    int pos = 0;
    for (int i = 2; i <= N; i++)
        pos = (pos + M) % i;
    return pos + 1;
}
```

Симуляция здесь не нужна — формула даёт ответ напрямую.

---

## `solvePartB(N, M, L)` — часть б)

Перебирает все стартовые позиции от 1 до N. Для каждой запускает симуляцию и сравнивает результат с L.

```cpp
int solvePartB(int N, int M, int L) {
    for (int s = 1; s <= N; s++) {
        Node* circle = buildCircle(N);
        Node* startNode = circle;
        while (startNode->number != s) startNode = startNode->next;

        int survivor = simulate(N, M, startNode, false);
        if (survivor == L) return s; // нашли стартовую позицию
    }
    return -1; // решение не найдено
}
```

Сложность: **O(N² × M)** — N вариантов старта, каждый симулируется за O(N × M).

---

## `main()` — точка входа

```
1. Считываем N и M, проверяем корректность.
2. Часть а) — вызываем solvePartA, выводим результат.
3. Часть б) — считываем L, вызываем solvePartB, выводим результат.
4. Проверка   — запускаем simulate с найденной позицией, сравниваем с L.
5. Демонстрация — для N ≤ 20 запускаем simulate с verbose=true.
```

---

## Сравнение частей а) и б)

| | Часть а) | Часть б) |
|---|---|---|
| Что ищем | Номер выжившего | Стартовую позицию |
| Алгоритм | Рекуррентная формула | Перебор + симуляция |
| Сложность | O(N) | O(N² × M) |
| Симуляция нужна | Нет | Да |
